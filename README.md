# 🎨 AlfaazCraft Frontend

AlfaazCraft Frontend is a modern React-based web application that provides a clean and engaging user interface for a poetry and shayari blogging platform.

It communicates with the backend REST API to fetch, create, and manage posts seamlessly.

---

## 🚀 Features

* 📝 Create and view poetry/blog posts
* 📡 API integration with backend (Spring Boot)
* ⚛️ Component-based architecture
* 📱 Responsive UI design
* 🔄 Dynamic data rendering

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* CSS
* Axios / Fetch API

---

## 🔗 API Configuration

Update API URL in your project:

```js
const API_URL = "http://localhost:8080/api/posts";
```

After deployment:

```js
const API_URL = "https://your-backend-url.onrender.com/api/posts";
```
